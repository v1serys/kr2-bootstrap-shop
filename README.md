# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина гаджетов и электроники «TechPulse», разработанную с использованием CSS-фреймворка Bootstrap 5.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap 5.3.3 через CDN;
- подключение `css/custom.css`;
- шапка страницы на основе сетки;
- адаптивная Bootstrap-навигация (`navbar`);
- hero-блок на сетке (`col-12 col-lg-6`);
- блок преимуществ (`col-12 col-md-4`);
- сетка популярных товаров (`col-12 col-md-6 col-lg-4`, отступы `g-4`);
- подвал страницы (`footer`).

## Используемые технологии

- HTML5;
- Bootstrap 5.3.3;
- CSS3;
- Git;
- GitHub.
